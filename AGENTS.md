# Noda agent instructions

Read [AGENTS.project.md](AGENTS.project.md) before editing or running checks.

- Keep public documentation, release notes and repository presentation in English.
- Fresh profiles start in English; preserve saved language choices and translations.
- Preserve user notes, queue sources and unrelated work. Use synthetic fixtures.
- Keep source-only contents in Git. Never add profiles, secrets, weights or caches.
- Report actual test and scan results, including known dependency advisories.
- A successful source check does not prove clean installation or public release safety.
- Pushes, releases, uploads and installed-app changes require explicit user direction.
