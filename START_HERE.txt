Getting started with Noda

Install Noda 1.0.2-beta.16 on Windows x64:

  https://github.com/Timaga/noda-local-ai-notes/releases/tag/v1.0.2-beta.16

Download Noda-Setup-1.0.2-beta.16-x64.exe from that release and run it.
Open Noda from the Start menu after installation. No developer tools are needed.
The repository and release are private; sign in with an account that has access.

To update, back up projects and the app profile, fully exit Noda through its tray
menu, then run the new version's Setup. Open the installed Noda to use the app.
All versions: https://github.com/Timaga/noda-local-ai-notes/releases

Fresh profiles start in English. Initial runtime and model downloads need internet.
This is an unsigned beta with known dependency advisories. See SECURITY.md.

Read README.md for requirements, features and the source-license conditions.
Read docs/USER_GUIDE.md for capture, data locations and backups.
Developers: docs/DEVELOPMENT.md covers source builds and local checks.
Maintainers: docs/RELEASING.md covers versioned installer releases.
