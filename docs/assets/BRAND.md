# Noda brand assets

The repository mark is the existing `frontend/assets/noda-bot-signal.svg`, copied without changing its paths or colors. The installed app icon remains unchanged.

- Use the SVG for the README and other scalable placements. Transparent PNGs are available at 512 and 128 pixels.
- Keep clear space around the mark; use a graphite background for the light gray strokes. Orange is `#FF7548`.
- `social-preview.png` is the 1280 × 640 GitHub sharing image. Its source is `social-preview.svg`; no external font or image files are embedded or required. Font fallbacks are Arial, Helvetica and sans-serif.
- Screenshots show the real English application renderer with synthetic English demonstration notes in an isolated Electron profile. The demonstration backend uses fixtures; the chat is not evidence of a live model evaluation.
