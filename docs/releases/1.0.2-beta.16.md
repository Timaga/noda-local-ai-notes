# Noda 1.0.2-beta.16

[**Download Windows Setup (x64)**](https://github.com/Timaga/noda-local-ai-notes/releases/download/v1.0.2-beta.16/Noda-Setup-1.0.2-beta.16-x64.exe) · [SHA256 checksums](https://github.com/Timaga/noda-local-ai-notes/releases/download/v1.0.2-beta.16/SHA256SUMS.txt)

Private prerelease for Windows 10/11 x64 with an AVX2-capable processor.

## Install or update

1. Download and run **Noda-Setup-1.0.2-beta.16-x64.exe**.
2. Follow Setup, then open the installed Noda from the Start menu or desktop shortcut.
3. On first launch, allow time for the local runtime and selected models to download. Internet access is required for these downloads.

**Updating:** back up your project folders and app profile, save edits, and fully exit Noda through its tray menu before running this version's Setup. This beta has no automatic updater.

## Changes

- New profiles start in English; existing saved language choices are retained.
- Windows folder validation rejects abbreviated 8.3 paths before project activation or backup. Choose full folder paths; junctions and symbolic links remain unsupported.
- The source repository, documentation and bundled license notices are prepared for this version.

## Known limitations

The installer is **unsigned**. A complete first launch on a clean Windows profile and real-model inference have not yet been validated for this build.

Known dependency issues remain: **19 repository alerts, including 5 high**. See [the security notes](../security-known-issues.md). This private beta is not approved for public binary distribution.

Model speed and memory requirements vary. Generated titles, tags, links and answers can be wrong.
